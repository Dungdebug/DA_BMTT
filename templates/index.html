Về Đề Tài Đồ Án Bảo Mật Thông Tin

  • Phân tích tĩnh chuyên sâu: Bóc tách mã băm (MD5, SHA-1, SHA-256, Imphash), đo Shannon Entropy từng section, phát hiện chênh lệch Virtual/Raw Size và các API tiêm nhiễm nhạy cảm.
  • AI Heuristics & XAI: Mô hình Machine Learning nhận diện mã độc và phát hiện File Lạ / Nghi vấn Zero-Day kèm giải thích lý do cụ thể.
  • Tri thức Đám mây: Tra cứu uy tín tập trung trên mạng lưới VirusTotal với hơn 70 hãng bảo mật.
  • Khắc phục Sự cố Tự động: Đề xuất Playbook ứng cứu sự cố và sinh mã lệnh PowerShell (.ps1) để cách ly file và vô hiệu hóa cơ chế duy trì độc hại.
